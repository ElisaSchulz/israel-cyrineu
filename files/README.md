# files/

Downloadable documents referenced by the site. Nothing here is generated —
drop the real files in and the links resolve.

Expected:

- `cv.pdf` — linked from the nav on **every** page. Add this before publishing,
  or remove the CV link from all six pages. Put a "last updated" date inside
  the PDF itself.
- `talk-YYYY-MM.pdf` — slide decks linked from `talks.html`.
- `poster-YYYY-MM.pdf` — posters linked from `talks.html`.

Keep filenames lowercase with no spaces; they become part of the public URL.
