# israel-cyrineu

Personal academic website for **Israel Molina Cyrineu**, PhD candidate.

Static HTML and CSS. No build step, no dependencies, no JavaScript — open any
`.html` file in a browser to preview it, or serve the folder locally:

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

Hosted on GitHub Pages from the repository root.

See **[CONTENT-GUIDE.md](CONTENT-GUIDE.md)** for what to edit and where.

## Structure

```
index.html            About / landing page
research.html         Research projects
publications.html     Papers, preprints, abstracts
talks.html            Talks and posters
teaching.html         Teaching and mentoring
assets/css/style.css  All styling
assets/img/           Portrait and figures
files/                CV, slides, posters
```
